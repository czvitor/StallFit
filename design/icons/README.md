# Ícone do app

Coloque aqui o ícone do app em alta resolução (SVG/PNG 1024×1024), antes de ser convertido para os mipmaps Android. Ao aplicar no app, isso vira:

- `app/src/main/res/mipmap-anydpi-v26/ic_launcher.xml`
- `app/src/main/res/drawable/ic_launcher_foreground.xml` / `ic_launcher_background.xml`
